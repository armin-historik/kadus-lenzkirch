Erste Arbeitsfassung für das Forschungsprojekt von Armin Wolfarth (November 2026).

## Status

**Noch nicht zur Veröffentlichung freigegeben.** Alle HTML-Seiten enthalten bewusst `<meta name="robots" content="index, follow">`. Die GitHub-Pages-Veröffentlichung und Verbindung mit `kadus-lenzkirch.de` sollten erst nach Quellen-, Rechte- und Domainprüfung erfolgen. Ein öffentliches Repository ist unabhängig davon öffentlich zugänglich; `noindex` schützt keine vertraulichen Inhalte.

Alle Seiten sind eigenständige HTML-Dateien im Repository-Hauptverzeichnis. Design: `assets/style.css`. Start: `index.html`.
